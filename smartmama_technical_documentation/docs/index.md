## Product boundary

SmartMama is a decision-support and coordination platform. It does not diagnose maternal conditions, replace clinical assessment, guarantee referral completion, or replace healthcare facilities.

> **AI is decision support, not diagnosis.** Risk classification should always be interpreted within the appropriate clinical workflow.

## Key capabilities

- CHV registration, verification, and household workflows
- Maternal and pregnancy records
- Household visit recording and risk classification
- Referral initiation and secure communication
- Role-based access and administrative oversight
- Audit logging, MFA, secure uploads, and API validation
- Mobile application and web dashboards
